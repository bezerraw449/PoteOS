# PoteOS

Como testar no celular?

1 - Baixe os arquivos do repositório e coloque-os na mesma pasta(Exceto README e LICENSE).

2 - Baixe o Termux e o Termux:x11

3 - Dentro do Termux, atualize todos os programas com o comando "pkg update && pkg upgrade" confirme as instalações digitando "y" e depois clicando em "Enter".

4 - Instale os repositórios com os comando disponíveis no próprio Termux(pkg install root-repo && pkg install x11-repo)

5 - Instale a janela gráfica com o comando "pkg install termux-x11-nightly"

6 - Instale os compiladores com o comando "pkg install nasm clang"

7 - Instale a máquina virtual Bochs com o comando "pkg install bochs"

8 - Localize a pasta dos arquivos com o comando "cd"(ex: cd /sdcard/Download/PoteOS)

9 - Use o comando "sh bash.sh".

10 - Abra o Termux:x11.

Obs: Até o momento, o PoteOS está em fase inicial e só possui a funcionalidade de entrada de teclado.
